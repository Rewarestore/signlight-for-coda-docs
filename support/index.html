Signlight for Coda

Support

Need help adding the Pack or understanding a status? Send a concise description to Reware Apps support.

What the colors mean

  • Red: no active sign-off exists.
  • Green: the signed and current fingerprints match.
  • Yellow: selected row values changed after signing.

Recommended setup

  1. Add the Pack to your Coda doc.
  2. Create a current fingerprint from the fields that matter.
  3. Use native buttons to copy the current fingerprint, user and time into the row.
  4. Render the row's status with the Signoff formula.

Scope

Signlight is a lightweight internal acknowledgement tool. It is not a legal electronic signature, tamper-proof record, regulated approval product or compliance certification. Support is best-effort and has no contractual service-level agreement.
